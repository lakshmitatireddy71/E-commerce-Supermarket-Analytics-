# E-Commerce Supermarket Analytics

## Project Overview

This project analyzes supermarket sales data using Excel, MySQL, Python, Power BI, and GitHub.

## Tools Used

* Excel
* MySQL
* Python (Pandas, Matplotlib)
* Power BI
* GitHub

## Key Analysis

* Total Sales Analysis
* Category-wise Sales
* Product-wise Revenue
* Customer Analysis
* Monthly Sales Trends

## SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* Aggregate Functions

## Power BI Dashboard

* KPI Cards
* Bar Charts
* Column Charts
* Pie Charts
* Slicers

## Skills Demonstrated

Data Cleaning, SQL, Data Analysis, Data Visualization, Dashboard Development, Version Control
